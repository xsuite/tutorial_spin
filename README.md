# Spin Tutorial

Jupyter notebooks and inputs for spin dynamics studies with Xsuite.

## Notebooks (run in order)

- `notebook_00_spin_twiss.ipynb` – baseline optics and spin twiss
- `notebook_01_monte_carlo.ipynb` – Monte Carlo spin tracking
- `notebook_02_resonant_dipolarization.ipynb` – resonant depolarization simulation
- `notebook_03_spin_tune_with_kicker.ipynb` – spin tune from twiss and tracking
